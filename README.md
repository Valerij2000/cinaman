# Синаман — адаптивный лендинг

Лендинг на Vite + TypeScript + HTML/CSS, вдохновлённый визуальной подачей Cinnabon, но с самостоятельным названием и текстами.

## Запуск

```bash
npm install
npm run dev
```

## Production-сборка

```bash
npm run build
npm run preview
```

## Перед публикацией

- Заменить изображения-референсы на собственные фотографии реальной продукции.
- Уточнить фактический адрес и заменить приблизительный поиск по району на точную метку карты.
- Заменить ссылки-заглушки Telegram и ВКонтакте на официальные страницы заведения.
- Добавить фактические цены и ассортимент.


## Фирменная палитра
- Navy: `#121E48`
- Deep navy: `#071D49`
- Teal: `#67CBC9`
- White: `#FFFFFF`

Палитра адаптирована под узнаваемые синий, бирюзовый и белый цвета бренда Cinnabon. Самостоятельное название проекта — «Синаман».
